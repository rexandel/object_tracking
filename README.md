### О проекте

Данный проект предназначен для сравнительного анализа различных алгоритмов корреляционного трекинга объектов на видео. Исследуются три популярных трекера:
* CSRT (Channel and Spatial Reliability Tracker)
* KCF (Kernelized Correlation Filters)
* MOSSE (Minimum Output Sum of Squared Error)

Сначала были [исследованы](https://github.com/rexandel/object_tracking/tree/main/cv2_trackers) встроенные в OpenCV реализации трекеров, затем KCF-трекер [был реализован вручную](https://github.com/rexandel/object_tracking/blob/main/homemade_kcf/kcf_tracker.py).

### Результаты тестирования

**Презентация**: [](https://github.com/rexandel/object_tracking/blob/main/presentation.pdf)

#### Видео 1: `cars_moving`
- **CSRT**: справляется с отслеживанием объекта вплоть до выхода за границы
- **KCF**: через пару секунд теряет отслеживаемый объект
- **MOSSE**: через пару секунд теряет отслеживаемый объект

**Победитель**: CSRT

#### Видео 2: `dribbling_ball`
- **CSRT**: теряет мяч и переключается на шорты спортсмена
- **KCF**: через несколько секунд полностью теряет отслеживаемый объект
- **MOSSE**: теряет мяч и переключается на шорты спортсмена

**Победитель**: CSRT

#### Видео 3: `people_walking`
- **CSRT**: справляется с отслеживанием объекта вплоть до выхода за границы
- **KCF**: справляется с отслеживанием объекта вплоть до выхода за границы
- **MOSSE**: справляется с отслеживанием объекта вплоть до выхода за границы

**Результат**: ничья между всеми тремя алгоритмами

#### Видео 4: `street_walking`
- **CSRT**: справляется с отслеживанием объекта, с небольшим смещением, до конца видео
- **KCF**: справляется с отслеживанием объекта, с средним смещением, до конца видео
- **MOSSE**: справляется с отслеживанием объекта, с большим смещением, до конца видео

**Победитель**: CSRT

#### Видео 5: `surfer`
- **CSRT**: справляется с отслеживанием объекта до конца видео
- **KCF**: справляется с отслеживанием объекта до конца видео
- **MOSSE**: справляется с отслеживанием объекта до конца видео

**Результат**: ничья между всеми тремя алгоритмами

### Сравнительная характеристика алгоритмов

#### CSRT
- **Преимущества**: лучшая точность отслеживания
- **Недостатки**: низкая скорость работы

#### KCF
- **Преимущества**: устойчивость к помехам и фонам
- **Недостатки**: чувствителен к быстрым изменениям

#### MOSSE
- **Преимущества**: высокая скорость и простота
- **Недостатки**: чувствителен к окклюзиям, ограниченность адаптивности

### Собственная реализация KCF

Собственная реализация метода не только не уступает по точности аналогу из библиотеки OpenCV, но даже превосходит в некоторых ситуациях:

- В видео 2 вместо полной потери объекта собственная реализация переключается на похожий объект
- В видео 4 позволяет сделать выделяемую область меньшего размера, но при этом отслеживание объекта происходит корректно
